Welcome to Type Toernooi!
In this game, your goal is type faster than your opponent. Battle the enemy by typing as fast as possible! Only then are you allowed to attack!
Instructions for launch:
1. Open the ZIP file in any IDE.
2. Navigate to Type_Project.java.
3. Run the code inside Type_Project.java.
4. Get ready to play!
On the bottom of the screen, you will see a box containing a random text that you have to type. The blue letters indicate your process, the red letters show how far your opponent is.
The letter displayed in white is the letter you have to type. Reach the end of the string before your opponent does to win the round! Having typed the text flawlessly, the winner's critical-
stamina bar increases. A full bar packs a bigger punch! Good luck!
Press escape to pause the game.
